# Plugin JSON schema (content/plugins/<slug>.json)
slug, name, category, tags[], url, maker, what, who: string(s)
demo (optional): { youtubeId, title, channel, channelUrl } — official demo video, embedded click-to-load from youtube-nocookie.com. Only videos from the tool's official YouTube channel (or linked from its official site/docs/README), embeddable (YouTube oEmbed returns 200; author_name/author_url = the official channel), current and about this tool. Never download or re-host. Omit if none qualifies.
updated: "YYYY-MM-DD" — date the entry was last checked against the official docs (used for "Last checked" and sitemap lastModified)
setup: [{ text: string, code?: string, language?: "bash"|"json"|"powershell"|"markdown"|"text" }]
prompts: string[]  (each rendered as a copyable block)
install (optional, MCP servers only): { name, transport: "stdio"|"http", command?, args?, env?, url?, requires: { runtime, auth }, notes?: string[], source, checked: "YYYY-MM-DD" } — verified install data. Renders the "Install in your client" section (Claude Code, Claude Desktop [stdio only], Cursor, VS Code, Codex snippets generated by src/lib/install.ts) and a row in /mcp-server-requirements/. stdio needs command + args (env optional, use placeholders for secrets); http needs url. Add it ONLY when package name, command, args, env vars and URL are copied from the server's official README/docs (put that page in `source`); otherwise leave it out. Windsurf is deliberately not generated (format unverified).
affiliate (optional): { url, cta, program } — an approved affiliate link for this tool (e.g. { "url": "https://firecrawl.link/pluginstackai", "cta": "Try Firecrawl", "program": "Firecrawl" }). Rendered under the official-site button with the visible "(affiliate link)" label, rel="sponsored nofollow" and a one-line disclosure linking /disclosures/#affiliate-links; /disclosures/ lists every program automatically. Add it ONLY when we are approved for that program and the listing is genuinely about that company's product. Never change the listing text because of it. Not included in /directory.json.
guides (optional): string[] — slugs of /guides/ pages to always show first in the listing's "Set it up / Fixes" block. Usually leave it out: the block is filled automatically from src/lib/guide-links.ts (guide roles/tags matched against the listing's category, tags, install transport/command/auth and the clients its setup names; max 3, none if nothing fits). To stop a guide appearing on a listing, add it to LISTING_EXCLUDE there.
